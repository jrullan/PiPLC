# PiPLC v0.1.32 Release Notes

Release: v0.1.32
Date: 2026-02-16

## Summary

- HMI runtime mode now hides editor chrome to provide a cleaner runtime presentation.
- Runtime uses a minimal toolbar and auto-sizes the window to match canvas resolution at 100% zoom.
- Fullscreen exit behavior now restores the correct chrome for editor mode and runtime mode.
