# PiPLC v0.1.40 Release Notes

Release: v0.1.40
Date: 2026-02-24

## Summary

- Added copy, cut, and paste support in the ladder editor for instructions, branches, and full rungs.
- Added undo/redo coverage for paste operations and improved action-state handling.
- Fixed false E004 duplicate-output validation errors across mutually exclusive branch paths.
- Fixed decorated-contact (TON/TOF) power-flow rendering inside branches.
