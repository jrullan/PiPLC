# PiPLC v0.1.42 Release Notes

Release: v0.1.42
Date: 2026-02-25

## Summary

- Added drag-and-drop rung reordering in the ladder editor.
- Added a horizontal insertion indicator and drag preview while moving rungs.
- Added undo/redo support for rung reorder actions and ignored no-op moves.
- Rung reordering is now blocked while simulation mode is active.
