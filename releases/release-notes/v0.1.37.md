# PiPLC v0.1.37 Release Notes

Release: v0.1.37
Date: 2026-02-22

## Summary

- Added composite provider support so Virtual, GPIO, Explorer HAT Pro, and Modbus TCP providers can be combined safely.
- Added remote provider management and completed user-facing instruction/memory docs for scheduled, date, and interval logic.
- Improved remote interval snapshots and watch diagnostics, including correct "Never triggered" behavior.
- Reduced runtime scan jitter with scheduler I/O cleanup and execution-path performance optimizations.
