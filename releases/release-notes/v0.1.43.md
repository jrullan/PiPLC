# PiPLC v0.1.43 Release Notes

Release: v0.1.43
Date: 2026-02-25

## Summary

- Added `INTERVALMS` instruction for millisecond-precision periodic triggers.
- Added `INTERVALMS` configuration with a period range from 1 ms to 2,147,483,647 ms.
- Added support for moving the instruction configuration dialog by dragging empty areas.
